# Popis API a akcí serveru (Apps Script)

Přesunuto z `CLAUDE.md` (kvůli velikosti kontextu). Strojově generovaný soupis akcí je v `docs/rozhrani.md` (`node nastroje/rozhrani.mjs`); tady je věcný popis – co která akce dělá, kdo ji smí a jaká platí pravidla. Při změně API aktualizuj obojí.

Popis rozhraní pro případnou výměnu serveru: **`docs/rozhrani.md`** (G4). Po každé změně API (nová akce, parametr, list, klíč Nastavení, časovač) spusť **`node nastroje/rozhrani.mjs`** a výsledek commitni. Novou akci zapiš do rozcestníku `doPostAkce_` vlastním řádkem `case 'akce': // účel` – komentář je popis v dokumentu. `./nasadit.sh server` spouští `--kontrola` a nenasadí, když aplikace / web / panel volá akci, kterou server nezná.
- **Veřejné GET** `?co=` (JSONP přes `&callback=`): `ping` (režim, verze, veřejný klíč Turnstile), `akce`, `terminy`, `dokumenty` (jen `Stav = zveřejněno` a viditelné pro veřejnost), `sbory` (název, okrsek, MH, JSDH, Sport – bez kontaktů), `organy` (členové orgánů; telefon/e-mail jen se souhlasem), `clanek&a=adresa` (detail příspěvku, jen zveřejněné pro veřejnost), **`web`** = vše pro `index.html` jedním dotazem (předem v mezipaměti, časovač `obnovitWebData`).
- **POST** (tělo JSON, `Content-Type: text/plain` kvůli CORS, pole `akce`, `token`, `klic`):
  - přihlášení: `kod` (+ `turnstile`), `overit`, `ja`, `odhlasit`; `nastaveniUlozit` = osobní nastavení uživatele okresu (Správa → Nastavení, sloupec Výchozí pořadatel v listu Uživatelé; vrací se v `uzivatel.nastaveni`); **`souhrn`** (`Souhrn.gs`) = ověření relace + položky k vyřízení pro odznaky, zvonek a přehled podle rolí – aplikace ho volá po přihlášení místo dřívějších osmi akcí (pro víc rolí ve třech souběžných dotazech s `casti` – `SOUHRN_SKUPINY`, `souhrnSoubezne()`; souhrn a portál čtou každý list jednou – `cteniJednou_` v API.gs, jen pro akce bez zápisu), plná data modulu načte až při otevření obrazovky (`zajistitData`, souběžně se souhrnem); portál sboru jen v roli sbor;
  - dokumenty (role Dokumenty/Správce): `dokumentyVse`, `zkontrolovatDisk`, `dokumentRozhodnout` (zveřejnit / vrátit / zamítnout / stáhnout, `upravy` vč. Pro koho);
  - kalendář (Termíny/Správce): `kalendar`, `ulozitAkci`, `ulozitTermin`, `zrusitAkci`, `zrusitTermin`;
  - portál sboru: `portal`, `nahlasitZmenu`, `zadostiSbor`, `zadostUlozit`, `zadostStahnout`, `zadostPriloha` (vždy `sbor` = skupina, server ověří členství);
  - žádosti – okres (Akce/Správce): `zadostiOkres` (se souběhy; přílohy jen u nevyřízených), `zadostPrilohy` (přílohy vyřízené žádosti v detailu), `zadostRozhodnout`;
  - `zaznamZmen` (Správce);
  - Můj sbor (`ZmenySboru.gs`): sbor `mujSbor`, `zmenaSboruPodat`, `zmenaSboruStahnout`; okres (Sbory/Správce) `zmenySboru`, `zmenaSboruRozhodnout`, `kontaktySboru` (jen čtení – obrazovka Kontakty sborů) – změny lidí a údajů sboru vždy schvaluje okres, provedení přes Admin SDK (skupina sdh-…, souhrnné skupiny, Sbory tady i v tabulce Skupiny OSH, Kontakty sborů, Členství skupin);
  - příspěvky (Příspěvky = zveřejnit / navrhnout, Správce): `prispevky`, `prispevekUlozit` (krok ulozit / odeslat / zverejnit, `upraveno` = kontrola souběhu), `prispevekRozhodnout` (vrátit s poznámkou / stáhnout), `prispevekSoubor`, `prispevekSouborSmazat`, `prispevekNahledy`, `prispevekSmazat` (zveřejnit / Správce, ne zveřejněný; navrhovatel jen svůj koncept);
  - majetek (Majetek/Správce): `majetekData` (+ `nabidka`, `rezervace`), `majetekUlozit` (typ majetek / osoba / kategorie / stavMajetku / stavVypujcky, `puvodni` = kontrola souběhu), `majetekVyradit`, `vypujckaNova` (`rezervace` = výdej z rezervace sboru), `vypujckaVratit`, `majetekFoto`, `majetekFotoNahrat`, `majetekPoskozeni`, `majetekNabidka` (nabízet sborům), `rezervaceZrusit`, `majetekProtokol` (předávací protokol / protokol o vrácení k vybraným výpůjčkám – PDF, neukládá se).
  - soutěže (`Souteze.gs`, B8, role Soutěže = všechny / MH / dospělí, kontrola podle pole Pro soutěže): okres `soutezeOkres`, `soutez`, `soutezUlozit` (přímo nebo `zadost` = ze schválené žádosti; zapíše řádek Akce → kalendář), `soutezStav` (koncept / přihlášky / uzavřeno / závod = nové odkazy pro rozhodčí / zrušeno; ověřeno → závod = oprava), `soutezStart` (los / pořadí), `soutezHarmonogram` (Hra Plamen: `nast` = nastavení rozběhů, `los` = časový rozpis bez střetů, `pdf`; posun podle zápisů `soHarmOdhad_` – kopie v `souteze.js`), `soutezRozradit` (uzlová štafeta: rozběhy u stojanů – sbor nikdy 2× v rozběhu, 2. pokus u jiného stojanu; `soRozdelit_`), `soutezTest` (jen TEST a název TEST…: `krok` prihlasky = vymyšlení závodníci / vysledky = náhodné časy), `soutezDruzstvo`, `soutezZverejnit` (PDF na Disk, `zrusit`), `soutezOz` (PDF organizačního zabezpečení z JSON `oz` soutěže), `poharUlozit` (Typ pohár / Hra Plamen = ročník: součet umístění v disciplínách kol, `soPlamenRocnik_`); sbor `soutezeSbor` (jen soutěže, které se sboru týkají: otevřené přihlášky – MH jen sborům s MH, kde má družstvo, které pořádá; ostatní jsou na webu; lehký seznam pro filtry a řádky – stav pro náš sbor, nejlepší umístění, ročník Plamenu; bez startovek a výsledků), `soutezSbor` (detail jedné soutěže až při otevření: informace a platba startovného, naše družstva, startovní pořadí, výsledky, „Kdy nastupujete“), `soutezPrihlasit`, `soutezOdhlasit` (vrací seznam i `detail`); **sborová soutěž** (vznikne schválením žádosti o pořádání soutěže, sloupec Pořadatel – skupina): pořádající sbor smí okresní akce `soutez`, `soutezUlozit` (bez názvu, termínu, místa, poháru), `soutezStav`, `soutezStart`, `soutezDruzstvo` (i hosté mimo okres), `soutezZverejnit`, `soutezOz` s parametrem `sbor` (kontrola `soMuze_`); veřejně **`zavod`** (`kod` z odkazu `zavod.html#k=…`, `krok` data / zapis / overit; zápisy s vlastním `klic`, při souběhu platí novější `zapsano`). Pořadí `soPoradi_` (i `soUzlovka_`, ZHVB `soZhvb_` / `soPoradiZhvb_`, Plamen `soPoradiPlamen_`) má kopii v `souteze.js` (závodní panel bez signálu) – měnit obě. ZHVB: hlavní je přepis startovní karty komisí (`renderKarta` v `zavod.js`, úkoly K2a… jen pro kontrolu); zápis z panelu nese jen změněná pole (start, cíl, K1–K8, čekání), `soZhvbZapis_` je slučuje po polích (novější vyhrává).
  - přestupy (`Prestupy.gs`, list Přestupy, bez rodného čísla a adresy): veřejně **`prestupVerejny`** (žádost z webu `?stranka=prestup`, Turnstile `prestup`, limity) a **`prestupZadatel`** (`k` = HMAC z ID, tajný klíč `PRESTUPY_KLIC` ve Vlastnostech skriptu, v tabulce otisk; `krok` stav / pdf / sken / zrusit); sbor `prestupySbor`, `prestupNovy` (přijímající sbor – jeho souhlas tím daný), `prestupSouhlas` (souhlas / nesouhlas s důvodem), `prestupSken` (sken lístku = souhlas sboru z jiného okresu), `prestupZrusit` (přijímající); okres (Přihlášky/Správce) `prestupyOkres`, `prestupRozhodnout` (provést s datem / zamítnout); oba `prestupPdf` (předvyplněný lístek HTML → PDF, neukládá se), `prestupSkenStahnout`.
  - vybavení u žádostí: `zadostiSbor` vrací i `nabidka` (jen věci s Nabízet sborům = ANO), `zadostUlozit` bere `data['Vybavení – ID']`; `zadostRozhodnout` (role Akce) schvaluje jen akci – vybavení zůstane ve stavu žádost a potvrzuje ho role Majetek.
  - vybavení bez akce (`MajetekSbory.gs`): sbor `vybaveniSbor` (nabídka + zápůjčky sboru), `vybaveniZadost` (samostatná zápůjčka – list Rezervace, sloupec Zápůjčka – ID), `vybaveniZrusit`; role Majetek `rezervaceRozhodnout` (potvrdit / zamítnout s důvodem – samostatné zápůjčky i vybavení schválených akcí, kontrola souběhu, e-mail sboru). **Akci schvaluje role Akce, vybavení vždy role Majetek.**
  - členové sborů (`Clenove.gs`, B17, listy **Členové** a **Změny členů**, bez rodného čísla a adresy): sbor `clenoveSbor` (jen čtení), `clenZmenaPodat` (ukončit / opravit), `clenZmenaZrusit`; okres (Přihlášky/Správce) `clenoveOkres`, `clenZmenaRozhodnout` (provést / zamítnout s důvodem), `clenoveImport` (jen Správce – export z evidencesdh.cz ve složce Nastavení `CLENOVE_IMPORT_SLOZKA`, páruje podle evidenčního čísla, chybějící = Aktivní NE, soubor do koše, sbory podle IČO / názvu / `CLENOVE_IMPORT_ALIASY`; z editoru `importEvidence`). Člena přidá i zápis přihlášky do evidence (`cleZPrihlasky_`) a provedený přestup (`cleZPrestupu_`). **Soupiska družstva**: `soutezPrihlasit` bere `data.soupiska` ([{ clen } nebo ručně { jmeno, prijmeni, narozen, pohlavi, ev, host }]), server ji ověří `cleSoupiska_` (věk v roce konce ročníku, ročníky z OZ mají přednost, pohlaví, nikdo ve dvou družstvech kategorie – ZHVB v celé soutěži) a uloží do sloupce Soupiska; pravidla `cleRozsah_` / `clePosoudit_` mají kopii v `soupiska.js` (prohlížeč, i PDF přihlášky) – měnit obě. Soupisky vidí jen sbor a okres (role Soutěže), pořadatel ne.
  - školení a kvalifikace (`Skoleni.gs`, B18, návrh `docs/skoleni.md`, role Školení = všechny / MH / dospělí): školení = řádek Akce (Typ školení) + list Školení (klíč Akce – ID; druh kurz / obnova / seminář / zkouška; víc kódů kvalifikací = přihlášený volí svou – odbornosti MH, společný kurz VM III. a II. stupně; u kurzu a obnovy každý účastník nová / obnova – sloupec Obnova, `skObnovaHodnota_`, kopie `skObn` v aplikaci); okres `skoleniOkres`, `skoleni`, `skoleniUlozit`, `skoleniStav` (koncept / přihlášky / uzavřeno / zrušeno), `skoleniVysledky` (`dokoncit` = vyhodnotit → list Kvalifikace s Platí do = konec + Platnost, u obnovy stará Aktivní NE), `skoleniPrezence` (PDF), `kvalifikaceOkres`, `kvalifikaceUlozit` (ruční zápis / úprava / ukončení); sbor `skoleniSbor`, `skoleniPrihlasit` (členové ze Seznamu členů nebo ručně, `kody` = odbornost u zkoušky; kontrola MH / dospělí a Min. věk – kopie `skVhodny` v aplikaci), `skoleniOdhlasit`; veřejně **`skoleniPrihlaskaWeb`** (přihláška z webu – jen školení pro veřejnost se sloupcem Přihlášky z webu = ANO; Turnstile `skoleni`, limity, e-mail povinný – potvrzení, Přihlásil = web, sloupce E-mail a Telefon vidí jen okres; zvolený sbor z okresu dostane e-mail a účastníka vidí v portálu), okres `skoleniOdhlasitOkres`; web v `?co=web` `skoleni` (jen veřejná, bez účastníků, `web` = lze se přihlásit), `kvalifikace` (katalog) a `testy` (jen cvičné sady). **Test na školení** (`Testy.gs`, listy Otázky testů a Pokusy testů): okres `testSpustit` / `testUkoncit` (odkaz `test.html#k=…` + QR jen v paměti stránky, kód jako otisk, do konce dne školení); okres **`testPoslat`** (rozešle odkaz + QR PNG z prohlížeče e-mailem na zadané adresy, max 100; odkaz se ověří proti otisku; pošle se skutečně i v TESTu – `posta_(…, 'vzdy')`); veřejně **`test`** (`krok` info / start / odevzdat – ověření datem narození, náhodný výběr ze sady zkouška, opakování do splnění, správné odpovědi nikdy do prohlížeče).
