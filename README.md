# Web OSH Praha – západ

Testovací verze nového webu a aplikace: https://test.oshpz.cz

| Cesta | Co to je |
| --- | --- |
| `index.html` | veřejný web (živá data z Apps Script API) |
| `Aplikace OSH.dc.html` | portál sborů a správa okresu |
| `support.js` | runtime stránek `.dc.html` – neupravovat |
| `_ds/` | vzhled Modernist |
| `data/` | soutěže a údaje sborů |
| `apps-script/` | serverová část (Google Apps Script, clasp) |
| `skupiny-script/` | zakládání Google skupin sborů |
| `docs/` | stav, plán, návody, nastavení testu |

Pro Claude Code: začni v `CLAUDE.md`.

Repozitář je veřejný – osobní údaje, kontakty a hesla sem nepatří.
